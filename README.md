# Student-Course-Tracker
A simple student course tracker, built using HTML, CSS, and JavaScript. This course tracker helps students to meet deadlines and track their courses.
## Features 
The student course tracker allows student to add their new courses, and it alos allows them to add the deadline of the course. In this wat students are able to check and meetup their deadline. Students are also able to mark the course as complete or pending. 

## Project Structure 
index.html 
style.css
script.js

## How it works 
Users can use the buttons available to use the web. They can add their courses, and also track their deadlines.
